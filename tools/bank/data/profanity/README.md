# Profanity lists

`en` and `fr` are from the [List of Dirty, Naughty, Obscene, and Otherwise Bad Words](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words) by Shutterstock, licensed under [CC BY 4.0](LICENSE). Copied unchanged on 16 Oct 2026.

The bank checks flag any item whose answer, alternates or sentence contains one of these words. Additions for this project go in `extra-<lang>`, not in the upstream files.
