# Building the GM app on a Mac

Oct 19, 2026 · how to get the iPhone app from this repo onto your phone and onto TestFlight.

The app is the GM screen. Players never install anything: they scan the QR code and play in their phone's browser.

## What you need

- A Mac with Xcode 26 or later, and Node 22 (`brew install node@22` or nvm).
- Your iPhone, with Developer Mode on (Settings → Privacy & Security → Developer Mode), and a USB cable for the first run.
- Your Apple Developer account, signed in to Xcode (Xcode → Settings → Accounts).

## First build

```sh
git clone https://github.com/aavanian/twototango && cd twototango
npm install
npm run sync -w @twototango/ios   # builds the web app, copies it into the Xcode project
npm run open -w @twototango/ios   # opens Xcode
```

Run `npm run sync -w @twototango/ios` again after every pull: it rebuilds the page and the banks inside the app.

In Xcode:

1. Wait for the package resolution (Capacitor and the host plugin) to finish in the left sidebar.
2. Select the **App** project, then the **App** target → **Signing & Capabilities**. Pick your team.
3. The bundle id is `app.twototango.gm`. If Xcode says it is taken, choose your own (for example `com.<you>.twototango`) and put the same value in `apps/ios/capacitor.config.json` (`appId`) so the next sync keeps it.
4. Plug in the iPhone, pick it as the run destination at the top, press Run (⌘R). With a free Apple ID (a "Personal Team"), the phone also asks you to trust the developer profile the first time: Settings → General → VPN & Device Management. A paid developer account skips this.

## Check on the phone

Each of these is something the desktop tests can't cover.

- [ ] **Join**: open a lobby, scan the QR with a second phone on the same Wi-Fi. The player page opens in Safari; try Chrome or Orion too.
- [ ] **Hotspot**: turn on Personal Hotspot on the GM phone, join it from the second phone, come back to the app. The QR changes to the hotspot address (172.20.10.x) within a few seconds.
- [ ] **Speech**: tap "Play word" with the silent switch on. The word is heard, in a British voice, and music playing in the room keeps going.
- [ ] **Screen**: during a game the GM screen never locks; in the lobby it does.
- [ ] **Interruptions**: mid-game, switch to another app for a minute, then come back. Phones may show "Paused — waiting for the game master's phone" meanwhile; either way they pick up where they were. Same after a phone call.
- [ ] **Kill**: mid-game, swipe the app away and reopen it. The game resumes at the same item.
- [ ] **Player phone locks**: a player locks their phone for 30 seconds. They are marked away and their item goes to the next player; when they unlock, they are back in.

If one fails, the Xcode console (⌘⇧Y) shows the app's logs; send them over with what you did.

## TestFlight

1. In [App Store Connect](https://appstoreconnect.apple.com) → Apps → **+** → New App: iOS, name "Two to Tango", your bundle id, any SKU.
2. In Xcode pick **Any iOS Device (arm64)** as the destination, then Product → **Archive**.
3. In the Organizer window that opens: **Distribute App** → App Store Connect → Upload, with the defaults.
4. After processing (10–30 minutes, you get an email), App Store Connect → your app → **TestFlight**: add yourself as an internal tester. The encryption question is already answered in `Info.plist` (no encryption).
5. Install the TestFlight app on the iPhone and accept the invitation.

For each new build, raise the build number (App target → General → Build), sync, archive and upload again.

## How it fits together

- `apps/client` is the web app. In the iOS app the GM page loads from `capacitor://localhost` and runs the game (`Session`); players' browsers load the same files from the GM phone over HTTP.
- `packages/ios-host` is the Swift plugin: an HTTP listener on port 5170 serving the page, a WebSocket listener on port 5171 for game messages (Network.framework), spoken answers, keep-awake, and the saved game and history as files in Application Support.
- `apps/ios/ios` is the Xcode project generated by Capacitor. `npm run sync` rewrites `CapApp-SPM/Package.swift` and copies the web build into `App/public`; don't edit those by hand.
